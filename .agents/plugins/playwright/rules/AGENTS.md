# Playwright en este proyecto

- Usá las herramientas de Playwright para revisar cómo se ve el sitio en el navegador.
- El sitio corre en `http://localhost:3000` con `npm run dev`. Antes de abrir un servidor nuevo, revisá si ya hay uno escuchando en el puerto 3000.
- Hay dos páginas: `/es` y `/en`. `/` redirige a una de las dos. Revisá ambas cuando cambies textos.
- Probá el modo claro y el oscuro, y también un viewport móvil (por ejemplo 390×844).
